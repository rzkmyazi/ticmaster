{{ icon('database') }} Sauvegarde serveur

PostgreSQL (recommandé en production) :

pg_dump "$DATABASE_URL" -Fc -f backup-$(date +%F).dump
pg_restore -d "$DATABASE_URL" --clean backup-2026-01-01.dump

SQLite (local) :

sqlite3 instance/ticmaster.db ".backup backup.db"
tar czf uploads-$(date +%F).tar.gz instance/uploads

Politique recommandée : 3 copies, 2 supports, 1 hors site. Fréquence quotidienne + avant chaque déploiement.

{{ icon('info') }} Procédure de restauration

  1. Placer la plateforme en maintenance (ou suspendre le trafic).
  2. Restaurer la base avec la commande correspondante ci-dessus.
  3. Restaurer le dossier instance/uploads à l'identique.
  4. Redémarrer le service et vérifier /sante.
  5. Se connecter avec le super administrateur et vérifier le journal d'audit.
